添加照片

    一键发布到 GitHub （可选，需要 Token）

    Token 只保存在当前浏览器的 localStorage 里，不会发到别的地方。 建议用 Fine-grained token，只授权这一个仓库的 Contents: Read and write。 发完约 1 分钟 GitHub Pages 才更新。

    没有 Token 也可以：点「下载压缩后的照片」，把它们放进 GitHub 仓库的 images/， 再用「复制 photos.js」的内容覆盖同名文件，提交即可。
