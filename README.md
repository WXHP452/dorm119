# 119 宿舍 · 宿舍小站

一个纯静态的宿舍主页：介绍 119 的六个人、挂照片、记日常。
没有后端、不用数据库、不用买服务器，**免费托管就能让别人访问**。

- 双击 `index.html` 就能看
- 手机 / 电脑自适应，支持深色模式
- 照片鼠标悬停会放大、浮起，点开看大图（键盘 ← → 翻页，手机左右滑）
- 右下角「＋ 管理」：**照片**和**成员**都能在这里改，改完点发布就同步给所有人

## 目录结构

```
dorm-site/
├─ index.html          # 页面骨架（文字都从 content.js 来）
├─ style.css           # 配色和样式（改颜色看最上面几行变量）
├─ app.js              # 渲染照片墙、成员、文字、背景（一般不用改）
├─ admin.js            # 「管理」面板：照片 / 成员 / 文字（一般不用改）
├─ photos.js           # ★ 照片清单
├─ members.js          # ★ 成员信息（名字、身份、一句话）
├─ content.js          # ★ 全站文字 + 背景图路径
├─ images/             # 照片文件夹
│  └─ 01.jpg           # 现在放的是你们那张合影
├─ tools/
│  └─ compress.py      # 可选：命令行批量压缩（不用面板时用）
└─ README.md
```

## 二、加照片（三种办法，挑一种）

### 办法 A：用面板，下载后上传（不用配置，推荐新手）

1. 点页面右下角的 **「＋ 管理」**，停在「照片」标签
2. 把照片拖进去（或点一下选文件，手机就是从相册选），可以一次多张
3. 每张可以改一句说明
4. 点 **「下载压缩后的照片」**
   - 浏览器会连着下载几个文件，名字是 `02.jpg`、`03.jpg`……（接着现有编号往后排）
   - 如果只存下来一张，去浏览器设置里打开「允许多个文件下载」
5. 点 **「复制 photos.js」**
6. 打开 GitHub 仓库：
   - 进 `images/` → `Add file` → `Upload files` → 把刚下载的照片拖进去 → `Commit changes`
   - 回到仓库根目录 → 点开 `photos.js` → 右上角铅笔 → 全选删掉 → 粘贴刚才复制的内容 → `Commit changes`
7. 等 1 分钟，刷新网址，照片就上去了

> 压缩、改尺寸、写代码这些事，面板都替你做完了，你只负责"传两个地方"。

### 办法 B：用面板，一键发布（配置一次，以后最省事）

需要在 GitHub 建一个有写权限的 Token，**只存在你这台设备上**，不进代码、不发给别人。

1. 打开 <https://github.com/settings/tokens?type=beta>
2. `Generate new token`
   - Token name：随便写，比如 `dorm119`
   - Expiration：可以选 90 天或更长
   - Repository access：选 **Only select repositories** → 只勾你那个宿舍仓库
   - Permissions → Repository permissions → **Contents: Read and write**（其他都不用给）
3. 生成后复制那串 `github_pat_...`（只显示一次）
4. 回到网站 → 「＋ 管理」→ 展开「发布到 GitHub」→ 填：
   - owner：你的 GitHub 用户名
   - 仓库名：比如 `dorm119`
   - 分支：`main`
   - Token：粘贴
5. 以后每次：选照片 → 点「发布到仓库」，等 1 分钟就好。手机上也能用。

> Token 相当于这个仓库的钥匙，**别填在别人的电脑或公共电脑上**。泄露了就去 GitHub 把它删掉，重新生成一个。

### 办法 C：完全手动

照片压缩到 300KB 以内 → 放进 `images/` → 在 `photos.js` 里加一行：

```js
const PHOTOS = [
  { src: "images/01.jpg", title: "119 全员到齐" },
  { src: "images/dorm-02.jpg", title: "阳台的晚霞" },
];
```

照片多、又不想用面板时，可以用脚本批量压：

```bash
pip install pillow
python tools/compress.py D:\照片\宿舍 images
```

它会按 EXIF 方向摆正、长边压到 1600px、**去掉 GPS 等元数据**，输出 `01.jpg`、`02.jpg`……

> ⚠️ 手动命名时别和已有文件重名，否则会覆盖掉原来那张。用面板生成的名字会自动往后排。

## 三、改成你们自己的

### 文字：全部在面板里改

点右下角 **「＋ 管理」** → **「文字」** 标签，整站的文字都在这里：

| 分组 | 能改什么 |
|---|---|
| 站名 | 宿舍名（导航、页脚、浏览器标题一起变） |
| 首屏 | 小字（年级/楼栋）、主标题（**回车就是换行**）、介绍 |
| 关于 | 小标题、那句话、正文 |
| 区块标题 | 成员区 / 照片墙 / 日常 的标题和副标题 |
| 页脚 | 两行字 |
| 小标签 | 首屏那三个小标签 |
| 数字 | 关于区那三块数字，可以加减、调顺序 |
| 日常 | 时间线，每条有「时间 / 标题 / 描述」，可以加减、调顺序 |

两个会自动替换的占位符：

- `{count}` → 当前成员人数（比如小标签写「{count} 个人」）
- `{year}` → 今年年份（页脚那行）

改完立刻在本机生效，点 **「发布文字与背景」** 才会同步给所有人。

> 也可以直接改 `content.js`（结构见文件里的注释），改完提交到 GitHub 一样生效。

### 背景图

还是在 **「文字」** 标签的最下面：

1. 点 **「选一张图片」**，挑一张（横图效果最好）
2. 会自动压到 2200px 宽、转成 JPG
3. 点 **「发布文字与背景」**，背景图会传到 `images/bg-时间戳.jpg`，同时写进 `content.js`

**「去掉背景」** 就恢复成原来的纯色。

> 背景图上面盖了一层半透明白/黑，保证文字还能看清，所以图片会是「隐约看见」的效果，不会喧宾夺主。深色模式下自动换成深色蒙层。

### 成员（三种办法，挑一种）

**办法 A：用面板改（推荐）**

1. 点右下角 **「＋ 管理」** → 切到 **「成员」** 标签
2. 直接改：头像字、姓名、身份、一句话介绍
3. 可以 **＋ 再加一位**、用 `↑ ↓` 调顺序、`✕` 删人
4. 改完立刻在本机生效；点 **「发布成员」** 所有人才能看到（需要 Token，见下面的 GitHub 配置）

> 没填 Token 也不怕：点「复制 members.js」，把内容粘到仓库的 `members.js` 里提交即可。

**办法 B：直接改 `members.js`**

```js
const MEMBERS = [
  { avatar: "东", name: "刘东杨", role: "119 成员", note: "待填：TA 的绰号是怎么来的？" },
  { avatar: "浩", name: "刘浩宇", role: "119 成员", note: "待填：TA 最常点的那家外卖。" },
];
```

- `avatar`：头像方块里的字（1 个，留空就取名字最后一个字）
- `name`：姓名
- `role`：身份，比如「寝室长 · 计算机」
- `note`：一句话介绍

改动后刷新页面就生效（本地）。**要让线上也变，得提交到 GitHub。**

**办法 C：改 HTML？不用了。** 成员已经不在 `index.html` 里，全部来自 `members.js`。

头像颜色会自动按顺序循环 `.a1`–`.a6`，想换色去 `style.css` 里搜 `.a1`。

## 四、发布到网上（免费）

推荐 **GitHub Pages**：免费、不用备案、自带 HTTPS。

### 1. 注册

<https://github.com> 注册（免费）。

### 2. 建仓库

右上角 `+` → `New repository`：

- Repository name：`dorm119`（或任何英文名）
- 选 **Public**
- 不要勾 `Add a README file`
- `Create repository`

### 3. 上传文件

点 `uploading an existing file`，把 `dorm-site` 里的**所有文件**（`index.html`、`style.css`、`app.js`、`admin.js`、`photos.js`、`members.js`、`images/`、`tools/`）一起拖进去，`Commit changes`。

> 拖的是 `dorm-site` **里面的内容**，别把这一层文件夹本身也拖进去，否则网址会多一层。

### 4. 开启 Pages

`Settings` → 左侧 `Pages` → Source 选 `Deploy from a branch` → Branch 选 `main`、目录 `/ (root)` → `Save`。

### 5. 等 1–2 分钟

```
https://你的用户名.github.io/dorm119/
```

如果仓库名是 `你的用户名.github.io`，地址就是 `https://你的用户名.github.io/`。

> 国内访问 GitHub Pages 有时慢。想更稳可以换 [Cloudflare Pages](https://pages.cloudflare.com/)（同样免费，连上仓库自动部署），或买国内服务器（那就需要备案）。

### 以后更新

- **网页上改**：仓库里点开文件 → 铅笔图标 → 改完 `Commit changes`
- **加照片**：用办法 A 或 B，最省事
- **用 Git**：

```bash
git clone https://github.com/你的用户名/dorm119.git
cd dorm119
# 改东西、加照片……
git add -A
git commit -m "加了几张照片"
git push
```

### （可选）绑自己的域名

买域名（`.com` 约 ¥60–100/年）→ 域名商后台加 `CNAME` 记录指向 `你的用户名.github.io` → 仓库 `Settings → Pages → Custom domain` 填域名。GitHub Pages 是境外服务器，**不需要 ICP 备案**。

## 五、发布前一定看：隐私提醒

这个网站是**公开的**，任何人（包括搜索引擎和爬虫）都能打开。

- ✅ **先问室友**：照片里有别人的脸，发之前至少在群里说一声。有人不想露脸就打码或别放。
- ❌ **别放**：门牌号 + 楼栋、宿舍钥匙照片、学号、身份证/学生证、手机号、课表、快递单、家庭地址。
- ⚠️ **照片元数据**：手机照片默认带 GPS 定位。面板和 `tools/compress.py` 都会在重新编码时去掉；用别的工具时留意。
- ⚠️ 现在这张合影能看出宿舍内部结构，如果哪天想低调，可以换成合照特写。
- 想更私密一点：别把仓库链接发到公开群，或者把仓库改名成不容易猜的名字（但 Public 仓库理论上能被搜到）。

## 六、常见问题

**Q：改了文件，网页没变？**
A：GitHub Pages 有 1–2 分钟延迟。本地看的话按 `Ctrl + F5` 强刷。

**Q：用面板加了照片，刷新就没了？**
A：面板里的照片只存在于当前页面（压缩在你浏览器本地完成）。要在所有设备上看到，必须走办法 A 的「上传」或办法 B 的「发布」。

**Q：点「下载」只存下来一张？**
A：Chrome / Edge 第一次会问「是否允许多个文件下载」，点允许；或者改成一张张点。

**Q：发布报错 401 / 403？**
A：401 是 Token 填错或过期；403 是 Token 没给这个仓库的 `Contents: Read and write` 权限。

**Q：照片墙一片空白？**
A：`photos.js` 语法错了（少了逗号或引号）。按 `F12` → Console 看红色报错。

**Q：某张显示「照片没找到」？**
A：`src` 里的文件名和 `images/` 里的不一致，注意大小写、后缀和空格。

**Q：能放视频吗？**
A：能，但 GitHub 单文件限制 100MB。建议传 B 站再嵌 `iframe`，或者只放链接。

**Q：别人能改我的网站吗？**
A：不能。仓库是公开只读的，只有你的账号（或你给的 Token）能提交。
